# Задача: Анонимная сессия по мнемоническому ключу и автоочистка (100 дней)

Статус: done

## Результат и границы

Пользователь сервиса получает персонализированный список ссылок без обязательной регистрации через автоматическую генерацию уникального мнемонического ключа (например, `cosmic-totoro-cookie-4081`). Ключ сохраняется в браузере, а при смене устройства или очистке кэша доступ легко восстанавливается вводом ключа. Если пользователь и его ссылки неактивны 100 дней, данные автоматически очищаются.

Не входит в срез: регистрация через email/пароль, OAuth2 провайдеры (вынесены в будущие задачи).

## Приёмка

- [x] Основной сценарий: первый визит -> автоматически выдается уникальный читаемый ключ -> ссылки привязываются к сессии.
- [x] Восстановление: сброс `localStorage` -> ввод ранее сохраненного ключа -> ссылки восстанавливаются.
- [x] Изоляция: пользователь A не видит и не может удалить/приостановить ссылки пользователя B.
- [x] Автоочистка: сессии и ссылки старше 100 дней без активности и кликов удаляются фоновым процессом.
- [x] Безопасность: в базе данных хранятся только SHA-256 хэши ключей.

## Контракт и порядок работы

1. **MemKey Generator (`apps/api/pkg/memkey`)**:
   - Генерация читаемых ключей с высокой комбинаторной энтропией (>8.6 млрд вариантов) в формате `<прилагательное>-<персонаж/животное>-<артефакт>-<4 цифры>`.
2. **Persistence (`apps/api/internal/database/migrations/00003_add_anonymous_sessions.sql`)**:
   - Таблица `anonymous_sessions` и колонка `links.user_id` с внешним ключом и каскадным удалением.
3. **Domain & Service (`apps/api/internal/domain`, `apps/api/internal/service`)**:
   - Доменные модели сессий, репозиторий, методы поиска, создания, очистки неактивных сессий (100 дней).
4. **HTTP API & Middleware (`apps/api/internal/handler`, `apps/api/internal/middleware`)**:
   - Эндпоинты `/api/v1/auth/session`, `/api/v1/auth/restore`, `/api/v1/auth/me`.
   - Заголовок `X-Session-Key` при операциях со ссылками.
5. **UI & State (`apps/web/src/entities/session`, `apps/web/src/features/session`)**:
   - Интеграция `X-Session-Key` в интерцептор Axios.
   - Модальное окно `SessionModal` (копирование ключа, восстановление, генерация нового, подсказка о 100 днях).
   - Бейдж в `Navbar` для открытия окна управления сессией.
