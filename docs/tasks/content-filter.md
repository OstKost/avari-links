# Задача: базовая проверка ссылок и предупреждение NSFW

Статус: done

## Результат и границы

При создании ссылка проверяется по списку запрещённых доменов оператора. Адреса с явными NSFW-маркерами требуют пометки, пользователь может пометить любую ссылку сам. Переход по помеченной ссылке показывает предупреждение и требует явного продолжения. Содержимое удалённой страницы не сканируется.

Источник требований: запрос пользователя от 2026-09-25. Текущее поведение: URL shortener.

## Приёмка

- [x] Обычная ссылка создаётся и перенаправляет без предупреждения.
- [x] NSFW-маркер требует пометки; помеченная ссылка показывает предупреждение, отмена не считает клик, продолжение перенаправляет и считает клик.
- [x] Запрещённый домен и его поддомены отклоняются при создании и при переходе по уже существующей ссылке.
- [x] Проверки и ограничения записаны ниже.

## Контракт и порядок работы

`POST /api/v1/links`: необязательное `is_nsfw: boolean`, ответ `Link.is_nsfw: boolean`. Ошибки `400` для необходимой пометки и `403` для запрещённого домена. SQLite migration добавляет столбец с default false. `GET /s/{code}` показывает HTML-предупреждение для NSFW; `POST /s/{code}/continue` с токеном подтверждения и очисткой cookie продолжает переход. `BLOCKED_LINK_DOMAINS` — список через запятую.

## Проверки и решения

`make check`: 8/8 (Go format, vet, race tests, build; web lint/build; harness), `.harness/runs/all-mv3l6zg8`. Сервисные тесты покрывают домены, поддомены, маркеры и старые ссылки; HTTP-тест покрывает предупреждение и запрет обхода без токена; SQLite-тест сохраняет пометку. В браузере проверены отказ без пометки, русское сообщение об ошибке, создание с пометкой, предупреждение, Tab между действиями и отсутствие горизонтальной прокрутки на 360 px. Продолжение в браузере не открывали на внешнем тестовом домене; HTTP-тест проверяет 302 и Location.

Ограничения: проверяется только URL, содержимое целевой страницы не анализируется; список запрещённых доменов задаёт оператор и по умолчанию он пуст. Эвристика NSFW распознаёт только явные маркеры в домене или сегментах пути. Дальнейшая модерация, внешние репутационные источники и обновление пометки у существующей ссылки — отдельные задачи.
