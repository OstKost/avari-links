# Задача: базовая проверка ссылок и предупреждение NSFW

Статус: in-progress

## Результат и границы

При создании ссылка проверяется по списку запрещённых доменов оператора. Адреса с явными NSFW-маркерами требуют пометки, пользователь может пометить любую ссылку сам. Переход по помеченной ссылке показывает предупреждение и требует явного продолжения. Содержимое удалённой страницы не сканируется.

Источник требований: запрос пользователя от 2026-09-25. Текущее поведение: URL shortener.

## Приёмка

- [ ] Обычная ссылка создаётся и перенаправляет без предупреждения.
- [ ] NSFW-маркер требует пометки; помеченная ссылка показывает предупреждение, отмена не считает клик, продолжение перенаправляет и считает клик.
- [ ] Запрещённый домен и его поддомены отклоняются при создании и при переходе по уже существующей ссылке.
- [ ] Проверки и ограничения записаны ниже.

## Контракт и порядок работы

`POST /api/v1/links`: необязательное `is_nsfw: boolean`, ответ `Link.is_nsfw: boolean`. Ошибки `400` для необходимой пометки и `403` для запрещённого домена. SQLite migration добавляет столбец с default false. `GET /s/{code}` показывает HTML-предупреждение для NSFW; `POST /s/{code}/continue` продолжает переход. `BLOCKED_LINK_DOMAINS` — список через запятую.

## Проверки и решения

Ожидаются сервисные, HTTP и SQLite тесты; `make check`; проверка браузерного сценария при доступности инструмента.
