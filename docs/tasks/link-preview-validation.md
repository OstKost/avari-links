# Задача: Валидация сайта и предпросмотр (Link Preview)

Статус: done

## Результат и границы

Пользователь получает интерактивную проверку сайта и карточку предварительного просмотра (OpenGraph метаданные: заголовок, описание, изображение, фавикон, статус доступности) при создании ссылки.
- Основной поток: Нажатие "Создать" запускает анимацию выезда карточки превью (CodeOrb смещается выше/в фоновый режим). При успешной доступности (200 OK) ссылка создаётся автоматически.
- Ошибочный поток: При недоступности сайта карточка показывает предупреждение, рядом с кнопкой "Создать" появляется кнопка обновления (Retry). Повторный клик на "Создать" создаёт ссылку принудительно.
- Вне среза: сохранение HTML-снимков или тяжелого скриншотера всего экрана (используются легковесные метатеги/OG-image страницы).

## Контракт и порядок работы

### API Контракт
- `POST /api/v1/links/preview`
  - Request: `{"url": "https://example.com"}`
  - Response (200 OK):
    ```json
    {
      "url": "https://example.com",
      "is_reachable": true,
      "status_code": 200,
      "title": "Example Domain",
      "description": "...",
      "image_url": "...",
      "favicon_url": "...",
      "site_name": "Example",
      "error": ""
    }
    ```

## Проверки и решения

- Ограничение чтения тела страницы: до 512 КБ для защиты от переполнения памяти при парсинге больших файлов.
- Таймаут запроса к сайту: 3.5 секунды.
- Сетевые ошибки возвращаются со статусом `200 OK` и флагом `is_reachable: false` для консистентной обработки на фронтенде.
